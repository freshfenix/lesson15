# Yellow Kitchen

Навчальний проєкт `Yellow Kitchen` - адаптивний лендинг сервісу доставки їжі, зібраний на Vite.  
Проєкт демонструє верстку головної сторінки, мобільне меню, секції з ресторанами та спеціальностями, а також базову інтерактивність на JavaScript.

## Опис проєкту

Сторінка імітує інтерфейс сервісу доставки їжі та містить:

- хедер із логотипом, посиланнями та мобільним меню;
- hero-блок із головним повідомленням;
- інформаційні переваги доставки;
- секцію ресторанів;
- форму для введення адреси доставки;
- карусель зі спеціальностями;
- футер із навігаційними посиланнями та контактами.

Проєкт є навчальним, тому частина посилань веде на `#` і використовується як макет для відпрацювання верстки та інтерактивної логіки.

## Технології

- HTML5
- CSS3
- JavaScript (ES modules)
- Vite
- Tailwind CSS v4

## Функціональність

- відкриття та закриття мобільного меню;
- закриття меню клавішею `Esc`;
- закриття меню по кліку на бекдроп;
- автоматичне дублювання елементів у каруселі спеціальностей для безперервного візуального циклу;
- підключення SVG-спрайта під час старту сторінки.

## Запуск локально

1. Встановіть залежності:

```bash
npm install
```

2. Запустіть dev-сервер:

```bash
npm run dev
```

3. Відкрийте адресу, яку покаже Vite, зазвичай `http://localhost:5173`.

## Збірка проєкту

Щоб зібрати production-версію:

```bash
npm run build
```

Після збірки результат потрапляє в папку `docs`, яка вже використовується як готова статична версія проєкту.

## Попередній перегляд збірки

```bash
npm run preview
```

## Структура проєкту

```text
lesson15.1/
├─ docs/          # готова збірка для публікації
├─ public/        # статичні файли, що копіюються без обробки
├─ src/           # вихідні HTML/CSS/JS-частини
├─ index.html     # головна сторінка застосунку
├─ package.json   # скрипти та залежності
└─ vite.config.js # конфігурація Vite
```

## Примітка для викладача або перевірки

Якщо потрібно оновити публічну версію, достатньо повторно виконати `npm run build` і використовувати вміст папки `docs`.
